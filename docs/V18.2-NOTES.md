# v18.2 — Aspect-aware award thumbnails

Certificate/award thumbnails now use Sanity image metadata to preserve the uploaded image's true aspect ratio. The gallery calculates a target footprint so landscape, square, and portrait awards remain similarly prominent without cropping or empty letterboxing. Student portraits remain circular and standardized.

Desktop target envelope: approximately 280 × 175 px maximum. Mobile target envelope: approximately 190 × 125 px maximum. The actual displayed width varies by certificate aspect ratio.
